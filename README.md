# Список ссылок с чекбоксами

Веб-приложение для управления списком ссылок с возможностью отмечать просмотренные элементы. Состояние чекбоксов автоматически сохраняется в облаке и синхронизируется между устройствами.

## ✨ Возможности

- 📋 Список из 9 ссылок на товары с сайтов Rozetka и Veloplaneta
- ✅ Возможность отмечать просмотренные ссылки чекбоксами
- ☁️ Автоматическое сохранение состояния в облачном хранилище JSONBin
- 🔄 Синхронизация данных между устройствами
- 📱 Адаптивный дизайн для мобильных устройств
- 🎨 Современный UI с градиентами и анимациями

## 🚀 Быстрый старт

1. Скачайте файл `index.html`
2. Откройте его в любом современном веб-браузере
3. Приложение готово к использованию!

## ⚙️ Настройка

Для использования собственного облачного хранилища:

1. Зарегистрируйтесь на [JSONBin.io](https://jsonbin.io/)
2. Создайте новый Bin
3. Получите API ключ
4. В коде замените значения:

```javascript
const BIN_ID = 'ВАШ_BIN_ID'; // Замените на ваш ID
const API_KEY = 'ВАШ_API_KEY'; // Замените на ваш ключ
```

## 🔧 Технические детали

**Используемые технологии:**
- HTML5
- CSS3 (с градиентами, анимациями и backdrop-filter)
- Vanilla JavaScript
- JSONBin.io API для хранения данных

**Структура данных:**
```json
{
  "checkboxes": {
    "1": true,
    "2": false,
    "3": true
  }
}
```

## 🔒 Безопасность

- API ключ находится в открытом виде в коде - подходит для демонстрационных целей
- For production рекомендуется использовать серверную часть для сокрытия API ключей
- JSONBin предоставляет HTTPS соединение для безопасной передачи данных

## 🛠 Кастомизация

### Добавление новых ссылок:
```html
<label class="link-item">
  <input type="checkbox">
  <div class="link-number">10</div>
  <a href="НОВАЯ_ССЫЛКА" target="_blank" class="link-text">Описание ссылки</a>

```

Замените CSS переменные в стилях для изменения цветов градиентов и акцентов.
